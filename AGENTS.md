# NetPause - Agent Guide

## Overview

NetPause lets users control the internet connection of the devices connected to the same network.

Main use cases:

- View a list of connected devices.
- Cut off the internet access from a specific device or all devices.
- Set a timer for re-enabling the internet access after a set delay.
- Adjust and persist board display brightness when the firmware advertises support.
